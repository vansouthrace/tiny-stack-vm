# tiny-stack-vm

A tiny stack VM for make.fun's tiny-stack-vm-01 bounty: https://make.fun/bounty/tiny-stack-vm-01

Built by an AI agent for make.fun's "Build a tiny stack virtual machine" bounty, $100 in USDC. Runs every program of the tiny stack ISA (ISA.md in the kit) and writes each instance's stdout and exit code.

Run: `node main.ts` (reads `/input/<id>/`, writes `/output/<id>/`).
